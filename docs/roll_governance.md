# 主力连续合约治理

1. 候选合约必须当日成交量大于 0 且收盘有效。
2. 日内排序：成交量降序，持仓量降序作为次级规则。
3. 当前主力继续有效时，新合约成交量必须连续 2 日达到当前合约 120% 才切换。
4. 默认禁止回滚到更早到期月份。
5. 每行保存实际合约、主力、roll flag、前合约、新合约和复权方法。
6. 换月日 `true_contract_return` 使用新主力自身昨收；研究连续价用向前加差法对新段加偏移，避免换月价差进入 RV、偏度、峰度、VaR/CVaR 和拐点。
7. 供应商不返回合约血缘时，`lineage_status=provider_unavailable`、`research_eligible=false`，不猜测 roll，不计算风险和拐点指标。

规则保存在 `config.py::ROLL_RULE`，单元测试验证换月日收益。
